# Fadokun Adebare — portfolio

Plain HTML, CSS and JavaScript. No build step, no frameworks.

## Files
- `index.html`, `about.html`, `work.html`, `honey-scotch.html`, `kms.html`, `modestly.html`, `apparel.html`, `playground.html`, `contact.html`: the pages
- `css/style.css`: all styles (colours live in `:root` at the top)
- `js/main.js`: mobile menu, scroll reveal, work filters, contact brief builder
- `images/`: project images
- `video/`: kms★ launch film, Modestly order-flow film and the 3D apparel clips (H.264 MP4)
- `fonts/`: self-hosted fonts (Jersey 10, Gochi Hand, Space Mono, Inter; SIL Open Font License)

## Run it
Open `index.html` in a browser.

## Put it online (free)
- **GitHub Pages:** push this folder to a repo, then Settings → Pages → deploy from the main branch.
- **Netlify / Vercel:** drag and drop this folder.
